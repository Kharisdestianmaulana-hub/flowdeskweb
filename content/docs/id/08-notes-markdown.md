# Editor Catatan Markdown

FlowDesk dilengkapi dengan editor catatan berbasis Markdown yang kuat dan *real-time*. Ini sangat cocok untuk menulis dokumentasi teknis, jurnal harian, atau draf artikel.

## Format yang Didukung
Editor kami mendukung format Markdown standar GitHub:
- **Tebal / Miring:** `**Tebal**` atau `*Miring*`
- **Daftar:** Gunakan `-` atau `1.`
- **Blok Kode:** Gunakan tiga *backticks* untuk menulis kode dengan penyorotan sintaks otomatis.
- **Tabel:** Anda bisa membuat matriks tabel dengan format markdown standar.

Ketik `/` (garis miring) di editor untuk membuka menu *Command* cepat yang memungkinkan Anda menyisipkan elemen tanpa mengetik format secara manual.
