# Apa itu FlowDesk?

FlowDesk adalah inovasi terbaru dalam dunia produktivitas. Alih-alih menyimpan data Anda di server pihak ketiga (*cloud*), FlowDesk menyimpan seluruh Proyek, Tugas, dan Catatan Anda langsung di perangkat penyimpanan lokal Anda.

## Mengapa Memilih FlowDesk?

1. **Privasi Absolut:** Tidak ada pelacakan, tidak ada sinkronisasi diam-diam, tidak ada server tersembunyi.
2. **Kinerja Instan:** Karena semua berjalan secara lokal, membuka tugas dan mencari catatan terjadi dalam hitungan milidetik.
3. **Masa Pakai Tanpa Batas:** FlowDesk tidak bergantung pada langganan bulanan. Sekali unduh, perangkat lunak ini menjadi milik Anda seutuhnya.
