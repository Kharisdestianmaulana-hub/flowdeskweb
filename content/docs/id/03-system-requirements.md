# Spesifikasi Sistem

FlowDesk dirancang dengan teknologi Avalonia UI dan .NET 10, membuatnya sangat ringan dan efisien dibandingkan aplikasi berbasis web atau Electron.

## Syarat Minimum

- **OS:** Windows 10/11, macOS 10.15+, atau distribusi Linux modern (Ubuntu, Fedora, Arch).
- **Prosesor:** Dual-core 1.5 GHz atau lebih cepat.
- **RAM:** Minimal 2 GB.
- **Penyimpanan:** Minimal 150 MB ruang kosong untuk instalasi aplikasi.

FlowDesk sangat optimal dan nyaris tidak membebani baterai laptop Anda saat berjalan di latar belakang.
