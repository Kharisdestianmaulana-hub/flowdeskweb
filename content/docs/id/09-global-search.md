# Pencarian Cepat (Global Search)

FlowDesk dirancang untuk kecepatan. Fitur pencarian global kami menggunakan pengindeksan lokal untuk memindai seluruh basis data Anda dalam hitungan milidetik.

## Cara Penggunaan
Tekan `Ctrl/Cmd + K` kapan saja saat aplikasi terbuka.

Sebuah *popup* akan muncul di tengah layar. Ketikkan kata kunci yang Anda ingat—entah itu nama proyek, isi dari suatu tugas, atau potongan kalimat dari catatan rapat minggu lalu. 

Hasil pencarian akan muncul secara *real-time* saat Anda mengetik. Gunakan tombol panah atas/bawah untuk menavigasi hasil, lalu tekan `Enter` untuk melompat langsung ke dokumen tersebut.
