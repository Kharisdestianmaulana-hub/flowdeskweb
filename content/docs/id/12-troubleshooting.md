# Pemecahan Masalah (Troubleshooting)

Berikut adalah beberapa langkah pertama yang bisa Anda lakukan jika aplikasi FlowDesk tidak merespons dengan baik:

## Langkah Pertama: Muat Ulang (Reload)
Terkadang, antarmuka pengguna hanya butuh disegarkan. 
Tekan `Ctrl/Cmd + R` untuk merestart *User Interface* tanpa menutup aplikasi.

## Langkah Kedua: Bersihkan Cache
1. Buka menu **Settings > Advanced**.
2. Klik tombol **Clear Local Cache**.
3. Aplikasi akan ditutup dan dibuka kembali secara otomatis. Jangan khawatir, file data utama Anda tidak akan terhapus.

Jika masalah berlanjut, Anda dapat memeriksa log aplikasi di folder instalasi Anda.
