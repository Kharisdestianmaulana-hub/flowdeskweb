# Instalasi & Persiapan

Memulai FlowDesk sangatlah mudah. Cukup ikuti langkah-langkah instalasi berdasarkan sistem operasi Anda di bawah ini:

## Pengguna macOS
1. Unduh file `.dmg` terbaru dari situs resmi.
2. Buka file yang diunduh.
3. Seret (drag) ikon FlowDesk ke folder **Applications**.
4. Buka FlowDesk melalui Launchpad atau Spotlight.

## Pengguna Windows
1. Unduh file `.exe` atau `.msi`.
2. Klik dua kali pada file instalasi.
3. Ikuti panduan *wizard* instalasi hingga selesai.

## Pengguna Linux
FlowDesk tersedia dalam format `.AppImage` dan `.deb`. Unduh versi yang sesuai dengan distribusi Anda, lalu jalankan melalui terminal atau manajer paket Anda.
