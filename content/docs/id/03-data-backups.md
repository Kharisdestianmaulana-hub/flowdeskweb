Dikarenakan sifat FlowDesk yang murni **Local-First**, data Anda tidak akan pernah meninggalkan komputer Anda. Semua data disimpan dengan rapi di dalam sebuah berkas *database* berformat `SQLite` standar.

### Pencadangan Otomatis (Automatic Backups)
Secara bawaan (*default*), FlowDesk secara otomatis mencadangkan *database* Anda setiap hari untuk mencegah kehilangan data jika terjadi kerusakan atau penghapusan tak disengaja. Anda dapat menemukan seluruh berkas cadangan ini di dalam direktori data aplikasi Anda.

### Praktik Terbaik (Best Practices)
Kami sangat menyarankan Anda untuk sesekali menyalin berkas-berkas cadangan `.db` tersebut ke cakram keras eksternal (*hard drive*), *flash disk*, atau ruang penyimpanan *cloud* pribadi Anda (seperti Google Drive atau Dropbox) sebagai langkah pengamanan ekstra.
