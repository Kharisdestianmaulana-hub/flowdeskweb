# Jalan Pintas (Keyboard Shortcuts)

Jadilah *power user* FlowDesk dengan menggunakan kombinasi tombol berikut untuk menavigasi aplikasi tanpa harus menyentuh mouse Anda.

## Navigasi Umum
- `Ctrl/Cmd + K` : Buka Jendela Pencarian Cepat (Global Search)
- `Ctrl/Cmd + 1` : Buka tab Dasbor
- `Ctrl/Cmd + 2` : Buka tab Proyek
- `Ctrl/Cmd + 3` : Buka tab Catatan
- `Ctrl/Cmd + ,` : Buka Pengaturan

## Manajemen Tugas
- `N` : Buat tugas baru
- `Space` : Tandai tugas selesai/belum selesai (saat disorot)
- `Del/Backspace` : Hapus tugas (saat disorot)
