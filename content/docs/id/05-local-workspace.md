# Ruang Kerja Lokal

Saat Anda pertama kali membuka FlowDesk, Anda akan diminta untuk menentukan **Ruang Kerja (Workspace)**.

## Apa itu Ruang Kerja?
Ruang kerja hanyalah sebuah folder biasa di dalam komputer Anda (misalnya: `Documents/MyFlowDesk`). 

FlowDesk akan menyimpan semua proyek, tugas, dan catatan Anda ke dalam folder ini ke dalam database SQLite dan folder lokal.
- Data proyek disimpan aman dalam `FlowDeskData/flowdesk.db`.
- Catatan disimpan sebagai file Markdown (`.md`).

## Multi-Workspace
Anda bisa membuat beberapa ruang kerja sekaligus (misalnya satu untuk Pekerjaan Kantor, satu untuk Proyek Pribadi). Gunakan menu di pojok kiri atas untuk beralih antar ruang kerja secara instan.
