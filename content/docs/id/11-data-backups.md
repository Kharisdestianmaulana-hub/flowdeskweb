# Pencadangan Data (Backups)

Karena FlowDesk tidak menyinkronkan data Anda ke *cloud* pihak ketiga, tanggung jawab pencadangan data sepenuhnya berada di tangan Anda. Ini adalah fitur, bukan *bug*.

## Metode Pencadangan yang Disarankan
1. **Cloud Sync Folder:** Simpan ruang kerja (Workspace) Anda di dalam folder iCloud, Google Drive, atau Dropbox. Aplikasi penyedia layanan ini akan mencadangkannya secara otomatis ke *cloud* Anda sendiri!
2. **Pencadangan Otomatis:** Bagi para *developer*, Anda bisa mengandalkan fitur pencadangan database otomatis harian dari FlowDesk yang tersimpan di `FlowDeskData/backups/auto` ke GitHub/GitLab pribadi Anda.

Jangan khawatir tentang kebocoran data dari sisi kami, karena kami tidak pernah menyentuh file lokal Anda.
