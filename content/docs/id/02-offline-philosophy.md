# Filosofi Offline-First

Di era modern, hampir semua aplikasi memaksa Anda untuk terhubung ke internet. Kami di FlowDesk menantang tren ini dengan pendekatan **Offline-First**.

## Prinsip Dasar Kami

- **Kedaulatan Data:** Data Anda adalah milik Anda. Kami tidak memiliki hak untuk melihat, mengolah, atau menjualnya.
- **Transparansi Format:** Semua data Anda disimpan dalam format `.json` dan `.md` biasa. Anda bisa membukanya dengan aplikasi lain kapan saja.
- **Ketahanan Jangka Panjang:** Karena Anda tidak bergantung pada server kami, FlowDesk akan terus berfungsi meskipun 10 tahun dari sekarang kami sudah tidak ada.

Bergabunglah dalam revolusi *local-first*!
