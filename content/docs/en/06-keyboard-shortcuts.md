# Keyboard Shortcuts

Become a FlowDesk *power user* by utilizing the following key combinations to navigate the app without touching your mouse.

## General Navigation
- `Ctrl/Cmd + K` : Open Global Search Window
- `Ctrl/Cmd + 1` : Open Dashboard tab
- `Ctrl/Cmd + 2` : Open Projects tab
- `Ctrl/Cmd + 3` : Open Notes tab
- `Ctrl/Cmd + ,` : Open Settings

## Task Management
- `N` : Create a new task
- `Space` : Mark task as done/undone (when focused)
- `Del/Backspace` : Delete task (when focused)
