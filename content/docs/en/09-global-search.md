# Global Search

FlowDesk is built for speed. Our global search feature uses local indexing to scan your entire database in milliseconds.

## How to Use
Press `Ctrl/Cmd + K` anytime while the app is open.

A popup will appear in the center of your screen. Type in any keywords you remember—whether it's a project name, task content, or a sentence fragment from last week's meeting notes.

Search results will appear in real-time as you type. Use the up/down arrow keys to navigate the results, and hit `Enter` to jump straight into that document.
