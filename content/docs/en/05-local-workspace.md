# Local Workspace

When you first open FlowDesk, you will be asked to define a **Workspace**.

## What is a Workspace?
A workspace is just a regular folder on your computer (e.g., `Documents/MyFlowDesk`). 

FlowDesk will save all your projects, tasks, and notes into this folder in an SQLite database and local folders.
- Workspace data is saved securely in `FlowDeskData/flowdesk.db`.
- Notes are saved as Markdown (`.md`) files.

## Multi-Workspace
You can create multiple workspaces simultaneously (e.g., one for Office Work, one for Personal Projects). Use the menu in the top left corner to switch between workspaces instantly.
