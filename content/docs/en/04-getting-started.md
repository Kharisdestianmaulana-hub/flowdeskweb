# Installation & Setup

Getting started with FlowDesk is incredibly easy. Just follow the installation steps based on your operating system below:

## macOS Users
1. Download the latest `.dmg` file from the official site.
2. Open the downloaded file.
3. Drag the FlowDesk icon into the **Applications** folder.
4. Launch FlowDesk via Launchpad or Spotlight.

## Windows Users
1. Download the `.exe` or `.msi` file.
2. Double-click the installation file.
3. Follow the installation wizard until completion.

## Linux Users
FlowDesk is available in `.AppImage` and `.deb` formats. Download the version that matches your distribution, and run it via terminal or your package manager.
